vmic_tts 1.0.0  かんたん説明書
==============================

文字を打つと、読み上げの声(VOICEVOX)に変えて、ゲームやDiscordの相手に届けるソフトです。
声を出せない場所で、会話に参加したいときに使います。

連絡先: 【ここに、連絡先を書いてください】


--------------------------------------------------
■ 最初に知っておくこと
--------------------------------------------------

・このソフトを使う人は、自分のPCに、次の2つが必要です。
    - VB-CABLE   (仮想マイク)
    - VOICEVOX   (読み上げの声)
  足りなければ、起動したときに、自動で案内が出ます。
  どちらも無料です。インターネットにつながっていれば、自動で入ります。

・聞くだけの人(話し相手)は、何も入れなくて大丈夫です。
  ふつうの声として聞こえます。

・初めてのときは、ダウンロードに時間がかかります(VOICEVOXは約2GBあります)。


--------------------------------------------------
■ はじめかた
--------------------------------------------------

1. vmic_tts.exe を、好きな場所に置きます。
   どこに置いても動きます。設定とログは、Windowsのユーザー用の場所に保存されるので、
   あとで別の場所に移しても、新しい版に入れ替えても、設定は残ります。

2. vmic_tts.exe をダブルクリックします。
   「Windowsによってパソコンが保護されました」と出たときは、
   「詳細情報」を押してから、「実行」を押してください。

3. 「足りないものがあります」と出たときは、
   「インストーラーを起動」を押します。
     (1) Windowsの確認画面(ユーザーアカウント制御)が出ます。「はい」を押します。
     (2) 黒い画面が開いて、自動でダウンロードとインストールが進みます。終わるまで、待ちます。
     (3) 「このデバイスソフトウェアをインストールしますか?」と出たら、「インストール」を押します。
     (4) 最後に「今すぐ再起動しますか」と聞かれたら、Y を押して、PCを再起動します。
   再起動したら、もう一度、vmic_tts.exe をダブルクリックします。

4. 画面が開いたら、ゲームやDiscordの「マイク(入力デバイス)」を、
   「CABLE Output」に変えます。
   (Discordは、「ノイズ抑制」と「自動入力感度」を、オフにしてください。
    読み上げの声が、途切れることがあります)

5. F8 キーを押すと、文字を入れる小さな画面が出ます。
   文字を打って、Enter を押すと、読み上げます。


--------------------------------------------------
■ キーの使い方
--------------------------------------------------

  F8                入力欄を出す / 閉じる
  Enter             (入力欄で) 読み上げる
  Esc               (入力欄で) 読み上げずに閉じる

  Ctrl + Alt + 1    「ナイス」
  Ctrl + Alt + 2    「ちょっと待って」
  Ctrl + Alt + 3    「了解」
  Ctrl + Alt + 4    「ありがとう」
  Ctrl + Alt + 5    「ごめん」
  Ctrl + Alt + 6    「お疲れ様でした」
                    (押すだけで、すぐ読み上げます。文章は、設定で変えられます)

  Ctrl + Alt + V    クリップボードの文字を読み上げる
                    (どこかで文章をコピーしてから、このキーを押します)

  F9                設定画面を開く
  Ctrl + Alt + Q    ソフトを終了する

画面を閉じたいだけのときは、右上の「ー」(最小化)を押してください。
最小化しても、キーは使えます。右上の「×」を押すと、終了するかどうか聞かれます。


--------------------------------------------------
■ 設定を変えたいとき (F9)
--------------------------------------------------

  ・声(話者)、スピード、高さ、抑揚、音量を、変えられます。
      「試し聞き」で、その場で確かめられます。
  ・「自分にも声が聞こえるようにする」にチェックを入れると、
      読み上げの声が、自分のスピーカーやヘッドホンにも流れます。
      (最初は、自分には聞こえない設定です)
  ・「定型文」タブで、ワンキーで読み上げる言葉を、追加・変更・削除できます。
      「初期値に戻す」で、最初の言葉に戻せます。
  ・「表示テーマ」で、画面の色を、ライト / ダークに変えられます(初期設定は、Windowsの設定に合わせます)。
  ・変更は、「保存」を押すと、確定します。


--------------------------------------------------
■ フルスクリーンのゲームで使うとき
--------------------------------------------------

ゲームが「フルスクリーン」の場合、F8 を押すと、ゲームの画面が一瞬消えることがあります。
入力欄を閉じると、ゲームは自動で戻ります。

画面が消えるのが困るときは、次のどれかを使ってください。

  ・ゲームの設定を、「ボーダーレス(ウィンドウ化フルスクリーン)」にする。 いちばん確実です。
  ・定型文のキー (Ctrl + Alt + 1 など) を使う。 画面は消えません。
  ・クリップボードの読み上げ (Ctrl + Alt + V) を使う。 画面は消えません。


--------------------------------------------------
■ うまくいかないとき
--------------------------------------------------

まず、ソフトの「ヘルプ」タブを見てください。
よくある困りごと(声が届かない、自分に聞こえない、など)の答えが入っています。

声が出ているか分からないときは、ヘルプタブの「テスト音を鳴らす」を押してください。
Windowsの「サウンドの設定」の「録音」で、「CABLE Output」のバーが動けば、
仮想マイクまでは、届いています。

それでも解決しないときは、次の手順で、状況を連絡してください。

  1. ソフトの「ヘルプ」タブの、「診断レポートを作る」を押します。
  2. 内容を確認します。
  3. 「ファイルに保存」か「クリップボードにコピー」を押して、連絡先に送ります。

  診断レポートには、次のものは入っていません(自動で伏せています)。
    ・読み上げた文章
    ・Windowsのユーザー名、PC名
    ・仮想マイク(CABLE)以外のデバイス名
  念のため、送る前に、内容を確認してください。

  ※ ログファイルには、読み上げた文章が、そのまま入っています。
    こちらは、送らないでください。


--------------------------------------------------
■ 知っておいてほしいこと
--------------------------------------------------

・VOICEVOXと、そのキャラクターの声には、利用規約があります。
  配信や動画の投稿などで使うときは、公式サイトの規約を確認して、
  必要なクレジット表記をしてください。
      VOICEVOX 公式サイト:  https://voicevox.hiroshiba.jp/
  ソフトの「クレジット」タブに、今の声のキャラクターに合わせた表記(例: VOICEVOX:ずんだもん)が出ます。
  「コピー」を押すと、貼り付けられます。使っているソフトの一覧も、同じタブにあります。

・読み上げた文章は、自分のPCの中のログファイルに、記録されます(14日たつと消えます)。
  保存場所: %LOCALAPPDATA%\vmic_tts\logs  (ソフトの「ヘルプ」タブの下にも、表示されます)
  このソフトが、文章を、外部に送ることはありません。
  (VOICEVOXのダウンロードと、VB-CABLEのダウンロードのときだけ、インターネットを使います)

・VB-CABLE は、VB-Audio社のソフトです。利用条件は、公式サイトで確認してください。
      https://vb-audio.com/Cable/

・このソフトを、スマホやMacでは使えません(Windows 10 / 11 用です)。


--------------------------------------------------
■ 新しい版に入れ替えるとき
--------------------------------------------------

新しい vmic_tts.exe で、古いものを置き換えるだけです(別の場所に置いても大丈夫です)。
設定と定型文は、そのまま引き継がれます。

--------------------------------------------------
■ やめるとき (アンインストール)
--------------------------------------------------

  ・vmic_tts: vmic_tts.exe を、削除します。
              (インストーラーで入れた場合は、Windowsの「設定」の
               「インストールされているアプリ」から、アンインストールします。
               設定とログも消すか、聞かれます。入れ直すときに、設定を残したいなら「いいえ」)
              設定とログを完全に消したいときは、次のフォルダも削除します。
                 %LOCALAPPDATA%\vmic_tts   (エクスプローラーのアドレス欄に、そのまま貼り付けて開けます)
  ・VOICEVOX: Windowsの「インストールされているアプリ」から、アンインストールします。
  ・VB-CABLE: VB-CABLE の公式ZIPに入っているセットアップを、
              管理者として実行して、「Remove Driver」を押します。そのあと、PCを再起動します。
