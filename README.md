# vmic_tts

文字を打つと、読み上げの声(VOICEVOX)に変えて、ゲームや Discord の相手に届けるソフトです。
声を出せない場所で、会話に参加したいときに使います。

- Windows 10 / 11 用です(スマホや Mac では使えません)。
- 聞くだけの人(話し相手)は、何も入れなくて大丈夫です。ふつうの声として聞こえます。

## ダウンロード

**[Releases(最新版)](https://github.com/ramerosu/yomiageruyatu-tool/releases/latest)** を開いて、`vmic_tts.exe` をダウンロードしてください。

- ダウンロードするのは、`vmic_tts.exe` だけです。`vmic_tts.exe.sha256` は、自動更新用の確認ファイルなので、不要です。
- 好きな場所に置いて、ダブルクリックすれば動きます。設定は、Windows のユーザー用の場所に保存されるので、別の場所に移しても、新しい版に入れ替えても、残ります。
- 「Windows によってパソコンが保護されました」と出たときは、「詳細情報」を押してから、「実行」を押してください。

## 必要なもの

次の2つが必要です。どちらも無料です。足りないときは、起動したときに、自動で案内が出ます。

| 名前 | 役割 | 補足 |
| --- | --- | --- |
| VB-CABLE | 仮想マイク | 入れたあとは、PC の再起動が必要です |
| VOICEVOX | 読み上げの声 | 約2GB あります。初回は、ダウンロードに時間がかかります |

## はじめかた

1. `vmic_tts.exe` をダブルクリックします。
2. 「足りないものがあります」と出たときは、「インストーラーを起動」を押します。
   - Windows の確認画面(ユーザーアカウント制御)が出たら、「はい」を押します。
   - 黒い画面で、自動でダウンロードとインストールが進みます。終わるまで、待ちます。
   - 「このデバイスソフトウェアをインストールしますか?」と出たら、「インストール」を押します。
   - 「今すぐ再起動しますか」と聞かれたら、`Y` を押して、PC を再起動します。
   - 再起動したら、もう一度 `vmic_tts.exe` をダブルクリックします。
3. 画面が開いたら、ゲームや Discord の「マイク(入力デバイス)」を、**`CABLE Output`** に変えます。
   - Discord は、「ノイズ抑制」と「自動入力感度」を、オフにしてください。読み上げの声が、途切れることがあります。
4. `F8` キーを押すと、文字を入れる小さな画面が出ます。文字を打って、`Enter` を押すと、読み上げます。

## キー操作

| キー | 動き |
| --- | --- |
| `F8` | 入力欄を出す / 閉じる |
| `Enter`(入力欄で) | 読み上げる |
| `Esc`(入力欄で) | 読み上げずに閉じる |
| `Ctrl` + `Alt` + `1` 〜 `6` | 定型文を、すぐ読み上げる(初期値: ナイス / ちょっと待って / 了解 / ありがとう / ごめん / お疲れ様でした) |
| `Ctrl` + `Alt` + `V` | クリップボードの文字を読み上げる(どこかで文章をコピーしてから押します) |
| `F9` | 設定画面を開く |
| `Ctrl` + `Alt` + `Q` | ソフトを終了する |

画面を閉じたいだけのときは、右上の「ー」(最小化)を押してください。最小化しても、キーは使えます。右上の「×」を押すと、終了するかどうか聞かれます。

## 設定(`F9`)

- 声(話者)、スピード、高さ、抑揚、音量を変えられます。「試し聞き」で、その場で確かめられます。
- 「自分にも声が聞こえるようにする」にチェックを入れると、読み上げの声が、自分のスピーカーやヘッドホンにも流れます(最初は、自分には聞こえない設定です)。
- 「定型文」タブで、ワンキーで読み上げる言葉を、追加・変更・削除できます。
- 「表示テーマ」で、画面の色を、ライト / ダークに変えられます。
- 「起動時に、新しい版が出ているか確認する」で、更新の確認を、オフにできます。
- 変更は、「保存」を押すと、確定します。

## フルスクリーンのゲームで使うとき

ゲームが「フルスクリーン」の場合、`F8` を押すと、ゲームの画面が一瞬消えることがあります。入力欄を閉じると、ゲームは自動で戻ります。

画面が消えるのが困るときは、次のどれかを使ってください。

- ゲームの設定を、「ボーダーレス(ウィンドウ化フルスクリーン)」にする(推奨)。
- 定型文のキー(`Ctrl` + `Alt` + `1` など)を使う。
- クリップボードの読み上げ(`Ctrl` + `Alt` + `V`)を使う。

## 更新

起動したときに、新しい版が出ていると、案内の画面が出ます。「更新する」を押すと、自動でダウンロードして入れ替え、再起動します。設定と定型文は、そのまま引き継がれます。

- 「ヘルプ」タブの「更新を確認」で、いつでも確認できます。
- 自動で入れ替えられないときは、ダウンロードのページが開きます。新しい `vmic_tts.exe` で、古いものを置き換えてください。
- 自動更新に対応していない古い版(1.0.0)を使っているときは、一度だけ、手動で入れ替えてください。

## うまくいかないとき

1. まず、ソフトの「ヘルプ」タブを見てください。よくある困りごと(声が届かない、自分に聞こえない、など)の答えが入っています。
2. 声が出ているか分からないときは、「ヘルプ」タブの「テスト音を鳴らす」を押してください。Windows の「サウンドの設定」の「録音」で、`CABLE Output` のバーが動けば、仮想マイクまでは、届いています。
3. それでも解決しないときは、「ヘルプ」タブの「診断レポートを作る」で、内容を確認してから、ファイルに保存するか、コピーして、下の連絡先に送ってください。

診断レポートには、読み上げた文章、Windows のユーザー名、PC 名、`CABLE` 以外のデバイス名は、入っていません(自動で伏せています)。念のため、送る前に、内容を確認してください。ログファイルには、読み上げた文章が、そのまま入っているので、送らないでください。

ウイルス対策ソフトに、危険と判断されることがあります。このソフトは、キー入力の監視をしていません(ホットキーは、Windows 標準の登録機能です)。

## プライバシーと通信

- 読み上げた文章は、自分の PC の中のログファイルに記録されます(14日たつと消えます)。保存場所は、`%LOCALAPPDATA%\vmic_tts\logs` です。
- このソフトが、文章を外部に送ることはありません。
- インターネットを使うのは、次のときだけです。
  - VOICEVOX と VB-CABLE をダウンロードするとき
  - 起動時に、GitHub で新しい版が出ているかを確認するとき(文章や設定は、送りません)

## VOICEVOX と VB-CABLE について

- VOICEVOX と、そのキャラクターの声には、利用規約があります。配信や動画の投稿などで使うときは、公式サイトの規約を確認して、必要なクレジット表記をしてください。
  - [VOICEVOX 公式サイト](https://voicevox.hiroshiba.jp/)
  - ソフトの「クレジット」タブに、今の声のキャラクターに合わせた表記(例: `VOICEVOX:ずんだもん`)が出ます。「コピー」を押すと、貼り付けられます。
- VB-CABLE は、VB-Audio 社のソフトです。利用条件は、[公式サイト](https://vb-audio.com/Cable/)で確認してください。

## アンインストール

- **vmic_tts**: `vmic_tts.exe` を削除します。設定とログも完全に消したいときは、`%LOCALAPPDATA%\vmic_tts` のフォルダも削除します(エクスプローラーのアドレス欄に、そのまま貼り付けて開けます)。
- **VOICEVOX**: Windows の「インストールされているアプリ」から、アンインストールします。
- **VB-CABLE**: VB-CABLE の公式 ZIP に入っているセットアップを、管理者として実行して、「Remove Driver」を押します。そのあと、PC を再起動します。
